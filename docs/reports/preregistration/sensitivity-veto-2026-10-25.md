# 预登记：否决臂的敏感性格栅（2026-10-25）

## 问题

报告 §11.5/§12 里"RULE 选股 + LightGBM 否决"通过了 CV 判据，而同一套构造换成 LSTM 否决就不通过。
两个否决模型给出相反答案，所以"ML 当过滤器有效"这个假设**未获复现**。本次格栅要回答的是：
在只改变**无关选择**（面板起点、否决模型）的情况下，该效应是否仍然成立。

## 固定项（不参与搜索）

- 分位 `--ml-veto-quantile 0.2`，全程不变。
- 配置：BIWEEKLY / p3 / mom120 / 绝对动量关闭 / equal 权重。
- 折计划：CPCV，6 块，`--cpcv-test-blocks 1`。
- purge：RULE=1，ML 臂=20（标签窗口）；embargo：LGB 臂=5，LSTM 臂=20（序列窗口）。
- 每块独立起算、从初始资本开始。

## 判据（三条 leg，缺一不可）

对同一个面板起点，比较该臂与 `rule`：

1. **Sharpe 中位数更高**；
2. **正收益块占比不低于**基线；
3. **maxDD 中位数不高于**基线 + 2pp。

一个上下文"通过"= 三条全中；一个臂"复现"= 在 **3/3** 个面板起点上通过。
只要有一个起点不通过，就记录为"未复现"，不得用其余两个起点的结果替代。

## 已知的先行结果（写在这里是为了防止事后叙述）

- 2016-01-29 起点：LGB 否决通过（0.5400 vs RULE 0.1881），LSTM 否决不通过（0.0841）。
- 本次格栅**不是**在寻找一个通过的臂，而是在检验已知的那个通过是否只是边界巧合。

## 允许的结论

- 3/3 通过 → 效应获得跨起点复现，该臂取得进入前向观察的资格（仍需计划 §9 的 forward leg）。
- 1/3 或 2/3 → 未复现，记录为负结果，RULE 保持生产。
- 0/3 → 该臂的 2016 起点通过是边界产物。
