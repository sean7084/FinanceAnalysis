# 预登记：折形状按 ICIR 裁决（2026-10-27）

## 问题

同一批臂在 rolling（固定 750 日训练窗）与 expanding（扩张窗）两种折计划下，哪个折形状给出
更稳定的逐折 IC？本文件在运行前写死格栅与判据；运行后不得改参。

## 固定项

- 面板：2016-01-29..2023-12-31，6 个 CVD 块，purge=1（RULE）/ 20（ML），embargo=5（LGB）/ 20（LSTM）。
- 选择器参数：BIWEEKLY / p3 / mom120 / 绝对动量关闭 / equal，与 row 256 一致。
- 只有折形状变化；特征集合与标签集合不变。
- 2024–2026 已释放进训练池，任何触及它的读数都是调优读数。

## 格栅

每个 cell 形如 `<arm>@<panel-start>`：

- `rule-rolling@2016-01-29`
- `rule-expanding@2016-01-29`
- `lgb-select-rolling@2016-01-29`
- `lgb-select-expanding@2016-01-29`
- `lstm-select-rolling@2016-01-29`
- `lstm-select-expanding@2016-01-29`

## 判据（运行前写死）

1. 主判据：逐折 ICIR（mean IC / sd IC）≥ **0.5**。
2. 辅助判据：正 IC 折占比 ≥ **2/3**。
3. 折形状裁决：对同一模型家族，ICIR 高者胜；ICIR 相等（差 <0.01）时，正 IC 折占比高者胜；
   两者都相等时判"两者都差不多"。
4. **不使用组合收益/SHARPE 作为裁决依据**——折形状是测量仪器变量，不是策略参数。
5. 若某臂的逐折 IC 全部不可测（例如 LSTM 的某折样本不足），该臂判"不可判定"，不补数据。

## 已知的先行结果（作为先验，不改变判据）

- 同一 RULE 配置在 rolling 与 expanding 下的组合 Sharpe 中位数都是 0.0791（§15/§16）。
- LGB 选择臂 rolling 0.4945、expanding −0.7320，但起点敏感（1/3）。
- LSTM 选择臂此前只有 cpcv 读数（0.1177 中位 Sharpe），rolling/expanding 未测。

## 允许的结论

- "rolling 的 ICIR 更高/更低/无差别"——三种都是合格结论。
- "LSTM 在某折不可判定"——记录实际折数与原因，不补齐。
- **不允许**据此改任何生产默认值；本批次只更新报告 §37。
