The app is bootstrapped in `src/main.tsx` with a React 19 root that wraps the tree in an `I18nProvider` (bilingual zh-CN/en-US persisted to localStorage) and then renders `App.tsx`. Routing is declarative via `react-router-dom`'s `createBrowserRouter`, with lazy-loaded page components under `src/pages/` (Dashboard, StockDetail, MacroContext, BacktestWorkbench, IndicatorBoard, AlertCenter, Settings, ModelMonitoring) mounted inside a shared `AppShell` layout (`src/components/layout/AppShell.tsx`) that renders a side navigation and `<Outlet />`. All HTTP and WebSocket communication is centralized in `src/lib/api.ts`, which defines typed DTO interfaces for every backend endpoint, handles JWT/API-key authentication (stored in localStorage or sessionStorage based on a user-selected mode), automatic token refresh on 401 responses, and exposes high-level fetchers like `fetchDashboardData`, `fetchScreenerRows`, `fetchBacktestRuns`, etc. Real-time alerts are handled by a custom `useAlertsSocket` hook that opens a WebSocket to `/ws/alerts/` with exponential backoff reconnection. Charts live in `src/components/charts/` (CandlestickChart using lightweight-charts, ProbabilityChart and BacktestComparisonChart using recharts). The build toolchain is Vite 8 with TypeScript 6, ESLint 9, Vitest with jsdom for tests, and a dev server that proxies `/api` and `/ws` to `http://127.0.0.1:8000`.
