Environment variables drive runtime behavior: `DJANGO_SETTINGS_MODULE` must be set to `config.settings` (or `config.settings.local` / `config.settings.production`), `DJANGO_SECRET_KEY`, `DATABASE_URL`, `REDIS_URL`, `CELERY_BROKER_URL`, `TUSHARE_TOKEN`, and various `MACRO_*` / `NEWS_BACKFILL_*` / `ALERTS_*` flags. `.env` loading is gated by `DJANGO_READ_DOT_ENV_FILE`. Celery workers auto-discover tasks from all installed apps via `app.autodiscover_tasks()`.
